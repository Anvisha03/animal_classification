# 🐾 Animal Classification Using Machine Learning

## Introduction
This project is an image-based animal classification system that uses deep learning to identify animal types from uploaded images.

## Technologies Used
- Python
- TensorFlow and Keras
- MobileNet
- HTML
- CSS
- JavaScript
- Flask

## Project Structure
- `frontend/` – Contains HTML, CSS and JavaScript files.
- `backend/` – Contains the Flask application and Python files.
- `backend/models/` – Contains the trained model and class names.

## Model
The project uses a trained MobileNet-based model saved in Keras format (`.keras`).

## Features
- Upload an animal image.
- Predict the animal category.
- Display the classification result.

## How to Run
1. Install the required packages using `requirements.txt`.
2. Run the Flask application.
3. Open the frontend in a browser.
4. Upload an animal image to get a prediction.
